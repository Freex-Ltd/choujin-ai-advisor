# 渋谷の食べログ → Excel + 統計

食べログのエリア一覧ページから店舗情報を集め、Excelブック（生データ + 統計シート + グラフ）を生成するツールです。

- `collect.py` … 食べログの一覧ページ（rstLst）を解析して CSV を出力
- `build_excel.py` … CSV から統計シート付きの xlsx を生成

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

### 手順1: データを集める

**方法A: ブラウザで保存したHTMLを読む（推奨）**

食べログは自動アクセスを制限しているため、この方法が確実です。

1. ブラウザで渋谷の一覧ページを開く
   <https://tabelog.com/tokyo/A1303/A130301/rstLst/1/>
2. 「ページを保存」で `saved/page1.html` として保存
3. 2ページ目以降も同様に保存（1ページ20件）
4. まとめて解析する

```bash
python3 collect.py --html "saved/*.html" -o shibuya.csv
```

**方法B: 直接取得**

`robots.txt` を確認し、許可されている場合のみ実行します。許可されていなければ中止します。

```bash
python3 collect.py --fetch "https://tabelog.com/tokyo/A1303/A130301/rstLst" --pages 20 --delay 3 -o shibuya.csv
```

`--delay` はページ間の待機秒数です。サーバに負荷をかけないよう 3 秒以上を推奨します。

### 手順2: Excelにする

```bash
python3 build_excel.py -i shibuya.csv -o 渋谷_食べログ.xlsx --source "食べログ 渋谷 rstLst 2026-08-24取得"
```

## 出力されるシート

| シート | 内容 |
|---|---|
| サマリー | 総店舗数・平均点・中央値・ジャンル数など |
| 統計_点数 | **星（点数）ごとの件数** を0.1点刻みで集計 + 棒グラフ |
| 統計_ジャンル | **飲食店の種類ごとの件数**・構成比・平均点 + 棒グラフ（上位15） |
| データ | 収集した生データ（オートフィルタ付き） |
| ジャンル展開 | 1店舗×複数ジャンルを縦持ちに展開（集計用） |
| 凡例・出典 | 各項目の定義と取得条件の記録 |

集計値はすべて数式（`COUNTIFS` / `COUNTIF` / `AVERAGEIFS` など）で書かれているため、
「データ」シートを差し替えれば統計が自動で再計算されます。

## 動作確認

ネットワーク接続なしで、パースから集計までが正しく動くか検証できます
（食べログのマークアップを模した架空データを使用し、実データは取得しません）。

```bash
python3 selftest.py
```

## 集計の定義

- **点数区分** … 0.1点刻み（下限以上・上限未満）。`3.00未満` と `4.00以上` は別枠。
  食べログで点数が `—` の店舗は「未評価」に分類し、平均点の計算からは除外します。
- **件数（主ジャンル）** … 食べログのジャンル表記の先頭1つで1店1カウント。合計は総店舗数と一致します。
- **延べ件数（全ジャンル）** … 複数ジャンル表記をすべて数えるため、合計は総店舗数を上回ります。
- **ジャンル一覧の範囲** … 主ジャンルと副ジャンルの和集合です。副ジャンルにしか現れないジャンル
  （例: 主ジャンルが「ラーメン」で副ジャンルが「つけ麺」のみの場合の「つけ麺」）も行として掲載され、
  その行の「件数（主ジャンル）」は 0 になります。
- **ジャンル別の平均点** … そのジャンルを掲げる全店（主・副を問わず）を対象に、未評価店を除いて算出します。

## 注意

- 食べログの点数は同社独自のアルゴリズムによるもので、**取得時点の値**です。時間経過で変動します。
- 一覧ページに表示されない店舗（掲載終了・非公開など）は含まれません。
- 取得したデータの利用は、食べログの利用規約の範囲内で行ってください。
- 大量・高頻度のアクセスは行わないでください。
